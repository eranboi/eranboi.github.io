Unity clone of the hypercasual mobile game Draw Climber. Draw custom leg shapes that animate and propel the character forward over obstacles.

## Mechanics

- **Touch drawing** - Draw leg shapes on screen
- **Procedural animation** - Drawn shapes animate as walking legs
- **Obstacle traversal** - Different leg shapes work better for different obstacles
