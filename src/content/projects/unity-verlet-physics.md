Verlet integration implementation in Unity for simulating soft bodies like ropes and cloths with tearable constraints.

## Features

- **Verlet Integration** - Position-based physics for stable soft body simulation
- **Ropes & Cloths** - Simulating flexible, connected structures
- **Tearable Constraints** - Rip apart ropes and cloths based on force
- **SAT Collision** - Separating Axis Theorem for collision detection
