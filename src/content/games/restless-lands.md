Solo developed Metroidvania project set in Norse mythology, in development since 2019.

## Key Systems

- **State machine** - Modular state machine framework for all game entities
- **Interaction system** - Custom inspector tools for designers
- **Inventory** - Full system with drag-drop and equipment
- **Localization** - Language system with hot-swapping support
- **Save/load** - Persistent save system for complex game states
- **Quest system** - Conditional triggers and objective tracking
